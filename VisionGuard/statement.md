# Project Statement

## Problem Statement
Traditional monitoring systems often require continuous human observation. VisionGuard aims to provide a computer-vision based monitoring system that processes a real-time camera stream to detect faces, recognize registered individuals, detect objects, and present monitoring information.

## Scope of the Project
The project covers live camera input, face detection, recognition of registered faces, object detection, real-time visualization, event logging, and basic monitoring alerts.

## Target Users
- Academic project demonstrators
- Campus/laboratory monitoring scenarios
- Computer-vision learners and researchers
- Small controlled environments for experimentation

## High-Level Features
- Real-time camera capture
- Face detection
- Face recognition for registered users
- Object detection
- Unknown-face indication
- Monitoring events and logs
- Configurable detection settings
- Modular source-code architecture
