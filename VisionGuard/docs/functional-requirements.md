# Functional Requirements

1. The system shall capture frames from a camera.
2. The system shall detect faces in each frame.
3. The system shall identify registered faces.
4. The system shall label unrecognized faces as Unknown.
5. The system shall detect supported objects.
6. The system shall display bounding boxes and labels.
7. The system shall log monitoring events when logging is enabled.
8. The user shall be able to stop the system using the Q key.
