# Dataset Description

VisionGuard uses two categories of data:

1. **Known-face images**: user-provided images stored under `data/known_faces/<person_name>/`.
2. **Object-detection model data**: the pretrained YOLO model and its associated pretrained knowledge.

No personal face images are included in this repository by default.

For an academic evaluation, document:
- Number of registered identities
- Number of images per identity
- Image conditions
- Lighting and pose variations
- Train/test split if a custom dataset is created
