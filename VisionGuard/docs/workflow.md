# Workflow

1. Start VisionGuard.
2. Open the configured camera.
3. Capture a frame.
4. Detect faces.
5. Compare detected faces with registered face encodings.
6. Detect objects in the same frame.
7. Pass recognition/object results to the monitoring engine.
8. Display bounding boxes, labels, and FPS.
9. Log monitoring events if enabled.
10. Continue until the user presses Q.
